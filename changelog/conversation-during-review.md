# Conversation during review — [Não lançado] (épico `epic/conversation-during-review`, PR #2536, MCP no change, schema v18)

## Alterado

- **Conversation window (CV1, stage #1881):** a new tool window stacked under Details in the right column, with its own strip button (icon `conversation`), a splitter (drag to resize, double click to reset) and a stored height (`conversationHeight`, default `size-tw-conversation` = 320 px). It has no `Ctrl+Shift` number, so the Help shortcut list and the guide's table do not change. Its body only shows the empty state for now.
- **One place for conversations (CV2, stage #1881):** every conversation now opens in the Conversation window: the Comments list, a pin, a citation chip, **New**, **Comment**, **Comment here** and sending a new conversation all show it there, and nothing is shown or written inside Details any more. The window has the state badge in its header, an "on <where>" line, the thread and the composer, and it does not follow the selection (the draft stays when the selection changes). The Conversations section of Details is now a list of the item's conversations (a row opens it in the window, **New** opens its composer there). The panel of a conversation without an item (layer, loose point, orphan) is gone: it opens in the window. The identity notice (**Fill in Settings**) appears in the window, in view and focused, on every request.
