# CR of the app, storage, viewer, scripts and CI — 2026-11-09 (epic `epic/cr-app-infra`, PR #1287, MCP 0.28.15, schema v18)

## Alterado

- Embeddable viewer (`mapping-viewer` 0.4.2): the package got ~52 kB smaller (Konva comes in only with the shapes used), `HostFonts` is now exported, the pixel ratio ceiling is applied when the first viewer is created (no longer when the module is imported), the default highlight colors come from the tokens and `dist-viewer/` is cleaned before each build (Konva's license notice stays at the end of the bundle). `attachPinchZoom`, `freezeGroup` and `thawGroup`, unused code, were removed.
- `loadLibraryFromUrl` requests each file only once and at most 6 at a time.
- Delivery flow (workflows): the Node and dependencies setup block of `ci.yml` became the local action `.github/actions/setup-deps` (the npm cache is no longer restored needlessly); the PR code of the MCP pre-releases (snapshot and rc) is compiled in a read-only job with no credential, and another job, without checkout, is the only one that publishes; the workspace files come out of a single pass of the script per job, and the MCP version comes from `stableRelease.mjs version`.

## Corrigido

- Dropping an image and another file (not an image) onto an existing image no longer swaps the image: it comes in as a new image and the notice of the ignored files appears. The swap only happens with exactly one dropped file, the same rule as the highlight when dragging.
- Pasting an image (Ctrl+V) with an import in progress is ignored, like dropping; before, two imports reset each other's progress.
- Ctrl+E with an import or swap in progress no longer exports, like the buttons.
- Ctrl+Shift+= (Ctrl++) zooms the canvas in, like Ctrl+=, instead of falling to the browser's zoom.
- With the app in English, Diagnostics shows the state of the fonts (missing, no `FontFace`, failed to load) and the problem "package too large to check" in English.
- When exporting the zip of an unnamed project, the file uses the language's default name (`project.zip` in English).
- When importing loose images into the project folder, if the copy to `images/` worked but the original could not be deleted, the image enters the project and the failure appears in Diagnostics (before, it was left duplicated and outside the project, without a notice).
- Embeddable viewer: a screen that disappears and comes back with the same size after the container changes is reframed; the stage and `clientToScreen` discount the container's padding and border; resizing redraws once per frame; with more distinct remote images on screen than the cache holds (64), the viewer no longer reloads the images in a loop (the evicted ones go back to the placeholder until the screen asks for them again); and the React wrapper passes through `fonts`, `measure`, `selectionColor` and `hoverColor`.
- Delivery flow: Deploy has `pages: write` and `id-token: write` only in the job that publishes, and a deploy in progress is not canceled by another (the superseded `build` still is); closing a PR cancels the MCP snapshot in progress (no `mcp-snapshot-pr<N>` pre-release is left orphaned); the rc builds of the PR and of `workflow_dispatch` share the same numbering group; pushing an rc tag by hand does not trigger the stable MCP; the `epic` job compares the epic name without a regex and shows the `gh api` error instead of blaming the missing changelog; `stableRelease.mjs epic` counts a release entry renamed by the old path.
- Interactive guide: the `<svg>` with focusable markings stopped being an image for screen readers (it becomes a group with the same name, and the buttons are announced); the annotation type is escaped when entering the page; the shortcut table comes from the app's window numbering (single source), and the guide CSS's design values come from the tokens.
- Cloud test scripts (`cloud-up.sh`, `cloud.mjs`, `mcp-stdio-client.mjs`, `round-guide.mjs`): `cloud-up.sh` ends with the message of item 6 when the window does not appear, accepts a relative round folder, waits for the static server up to a deadline and checks the MCP version by exact text; `cloud.mjs` and `round-guide.mjs` run in a path with an accent and a space and `round-guide.mjs` accepts `ALL`; `saveFile` says when the save dialog does not appear; `listWindows` reads the window names in a single command; `mcp-stdio-client.mjs` does not cut multibyte characters, rejects at once a request made after the server exits and gives a short message when the server does not start; the R15 image server answers 404 without `foto.png`; the example zip ignores `.DS_Store`, `Thumbs.db` and `node_modules`.
- The library problems banner shows "file not found" translated ("file not found" in English (US)); before, it always came out in Portuguese.
- MCP 0.28.15: the "file not found" problem of library validation (`validate_library` and the batch warnings) gains the optional fields `code` (`file-not-found`) and `target`; the `message` text does not change.
