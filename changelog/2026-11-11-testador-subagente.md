# Tester with a subagent per batch — 2026-11-11 (épico `epic/testador-subagente`, PR #1664, MCP unchanged, schema v18)

## Alterado

- Tester prompt (`docs/TESTING-NUVEM.md`): the main session no longer runs steps. It sets up the environment (items 1 to 6 of "First 10 minutes"), writes the report header, hands each batch to a subagent on the same machine (one batch at a time, never two) and joins the report with `cat >>`, without opening the file. Item 7 tells it to assemble the batches and read the briefing.
- `docs/TESTING-NUVEM-CONSULTA.md`: new section "Subagent per batch" (`cloud.mjs secao consulta.subagente`), with the briefing template, the assembly of the report and the replacement of a subagent that fails. Read before the first batch (R0).
- `round-guide.mjs --faixas <roteiro|faixa…>`: prints one line per batch, in the guide's order, without R0. A test script of up to 20 steps is one batch; above that, ranges of up to 20 steps (`R25.1-R25.20`…); the step that `passo` joins to the previous one (R22.6a) is not separated.
- `cloud.mjs passo <Rn> --preparo`: prints only the part of the test script before the first step (title, "What it covers", Setup and code blocks, like the `tinta`, `sonda` and `medir` functions of R25), with the 25 thousand cut. An item that is not a whole test script exits with code 2.
- The tester's 300 thousand ceiling is now checked by the queue (`docs/TESTING-NUVEM.md`, "Context up to 300 thousand", rewritten): it applies to every tester session, measured on the main session by `get_session`, and the main session with subagents per batch is what guarantees it. The excess is recorded by whoever coordinates, without holding the stage, without redoing the round and without calling the owner (the "move test scripts among the 5 blocks" and the "call the owner" are removed). `painel.py cost` of `testador` or `reteste` above 300 thousand prints "acima do teto do testador (300 mil): <id> <ctx>", and `show` gains the line `testador acima do teto:`. The `implementar-fila` skill writes the excess to the `log` when archiving the session and comments on it, at closing, on the pinned `roadmap` "Tester context ceiling". The round summary (`docs/FLOW.md`) gains the **Contexto** column and the **Contexto:** line.
