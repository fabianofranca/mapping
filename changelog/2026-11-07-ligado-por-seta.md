# Linked by arrow — 2026-11-07 (epic `epic/ligado-por-seta`, PR #720, MCP 0.24.1, schema v15)

## Adicionado

- The **Linked by arrow** section in the marking's Details: it appears when the marking has an arrow and lists one row per arrow, first those that leave it and then those that arrive. Each row shows the direction (**Goes to** / **Comes from**), the other end in a button that selects it, the arrow's name and a **Select the arrow** button. Below come, read-only, the annotations of the other end in the visible layers, grouped by layer, and those of the arrow itself under **On the arrow**; with none, the row says "No annotations in the visible layers." It serves, for example, someone working on a button to see the loose analytics table linked to it, without searching for it on the canvas. The section also appears in the Details of a proposal review, reading the project in view (Current or Proposed).
