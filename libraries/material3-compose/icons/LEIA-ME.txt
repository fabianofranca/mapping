Icons of the Material 3 (Compose) package
=========================================

The specialization (material3-compose.spec.json) declares the set in "icons":

  - icons/material-icons.json (mapping-icons, formatVersion 2, viewBox 24 x 24)

The set is a subset of Material Icons in the Filled variant (Compose's Icons.Default), with the
paths taken from the npm package @material-design-icons/svg 0.14.15 ("filled" folder), licensed
under the Apache License 2.0. The license text is in LICENSE-material-icons.txt, next to it.

In formatVersion 2, "mirror": true marks the icons that androidx puts in
Icons.AutoMirrored.Filled (arrow_back, arrow_forward, keyboard_arrow_left, keyboard_arrow_right,
list, send, help…): in the rtl reading direction the drawing flips them horizontally. The list
(24 icons of the set) comes from the androidx.compose.material:material-icons-core and -extended
1.7.8 artifacts (the latest stable: the pinned androidx commit, 5113b82a…, does not include the
icon files, which are generated and published separately).

The name of each icon is the package's, in snake_case (home, keyboard_arrow_right). The icon
fields of the types store the Compose name (Home, KeyboardArrowRight, what goes in
Icons.Default.<name>), and the component translates one into the other.

To add an icon: take the <name>.svg from the package's "filled" folder, copy the "d" of the
<path> into a new entry of "icons" (an icon with several paths takes one "paths" item per
<path>), and add the Compose name to the "suggestions" of the icon fields and to the
$switch of names of the icon component.
