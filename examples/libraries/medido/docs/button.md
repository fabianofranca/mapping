# Botão

Botão com rótulo e dois tons: neutro (cinza) e erro (vermelho).

Tipo de anotação: `button` (Botão).

## Origem medida

- Sistema `dom`: o nó de classe `btn-primary`.

| Campo   | Caminho em `props` | Valores               |
| ------- | ------------------ | --------------------- |
| `label` | `label`            |                       |
| `tone`  | `tone`             | `danger` vira `error` |
