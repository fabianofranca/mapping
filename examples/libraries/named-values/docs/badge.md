# Badge

A pill that reads **one field of a composite**: the text size is `{ "$token": "title.size" }`, the size of the library's `title` text style. The fill is `primary` and the text `on-primary`, which follow the theme and the contrast.

Annotation type: `badge` (Badge).

| Field   | Type   | Description      |
| ------- | ------ | ---------------- |
| `label` | string | The badge's text |
