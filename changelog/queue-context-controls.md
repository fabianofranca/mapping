# Queue context and cost controls — [Não lançado] (épico `epic/queue-context-controls`, PR #0, MCP unchanged, schema v23)

## Alterado

- The PR gate of the context hook (`scripts/ci/contextGuard.mjs`) no longer refuses text that only mentions `gh pr create` (a heredoc body or a quoted string, such as a multi-line commit message) and now also sees the other ways of opening a PR: `bash -c`/`sh -c`/`eval`, a `curl` POST to the pulls endpoint and the GraphQL `createPullRequest` mutation (`gh api graphql` or `curl` to `/graphql`). A script file, a command built in a variable, another HTTP client and a query read from a file stay best effort.
- A hook change on `main` now reaches the epics in progress: before each phase, fix, retest or tester session, the coordinator (and the orchestrator outside the queue) runs `node scripts/ci/hookSync.mjs origin/epic/<name>` and, when `main` changed a hook file since the epic's base, brings `main` into the epic through a sync session `SM<k>` before creating the session (`docs/FLOW.md`, "Main before a session (hook files)"). An epic that edits the hook itself does not loop, and a shallow history gives `no base` and a sync, never a silent skip.
- `painel.py outliers` gains `--encerradas-desde <ISO>`: the medians still come from the base (not from the window) and only the stages that ended from the date on are listed, with `listed: ended from <ISO>` in the header; without the flag the output does not change. It is cited in `.claude/skills/implementar-fila/SKILL.md` ("Panel") and `.claude/skills/supervisionar-fila/SKILL.md` ("On-demand cost").
