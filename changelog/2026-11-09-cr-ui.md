# CR of the interface — 2026-11-09 (épico `epic/cr-ui`, PR #1236, MCP 0.28.12, schema v18)

## Corrigido

- Diagnostics: the "Copied" notice disappears after 2 seconds and does not stay on screen after Copy and Clear the log.
- Manage perspectives, "Who sees it": when saving fails, the selector goes back to the perspective's value (instead of showing "Only me" with the perspective still for everyone) and the error message disappears on the next change that works.
- Manage perspectives, rename: the field restarts from the current name on cancel and reopen, and shows the new name when it changes externally (undo, reload).
- Right-click menu, "Send to perspective": the submenu opened by hovering closes when leaving the item, also in Main, and closing with ← does not make the next click or Enter be ignored.
- New-version notice: if the project could not be saved, the app no longer reloads; the notice stays and says it did not save, and clicking "Update" again tries to save once more.
- Import specialization package: the size limit counts bytes (not characters) and is checked before decompressing each file of the zip and on each file read from the folder, stopping at the first one that goes over the limit.
- Annotation Details, "Linked to": when the saved owner stopped being valid, the field shows the real value (marked as an invalid owner) instead of staying blank, and the person can change it.
- Layers: with a perspective open and the project read-only (or under review), each layer's visibility checkbox and "Show all" are disabled, instead of the checkbox switching without changing anything.
- Container Details (no image): the width error, the height error and the color error appear under the field itself and disappear when another container is selected.
- Free annotation pairs: a pair's error (and the invalid-field notice) stays attached to it; when removing a row, the message does not move to the pair that takes its place.
- Reference picker: the searched snippet is highlighted in the right place also in texts with letters like "İ".
- Reference picker: Enter (with or without Alt) only chooses the target; Alt+Enter inside the picker no longer adds an empty row to the table.
- Table, "References will break": the row name in the confirmation always comes from the current row, also after an external reload with the dialog open (before, "Row 0" could appear).
- Comments, "Delete conversations…": the date of "With the last message before" counts as midnight in its time zone; the preview and the delete use the same limit (in UTC-3, "before 11/01" now includes the messages of 10/31 after 9 pm).
- Comments, field with citations (@): the field no longer announces attributes that do not exist for it; the options list is only pointed to while it is open.
- Comments window: the accessible name of the conversation button says "(unread)" when there is an unread message, in Portuguese and in English.
- Review, dependency notices: two notices that differ only in the other item involved do not swap places when one of them disappears.
- Review, "Accepting also removes:": the lists of markings and arrows that go out with the image say "and N more" when they go over 12, like the annotations one.
- Review, Details: clicking on the background and then switching items by N or C no longer takes focus to Details.
- Review, tree of a superseded proposal: the list measures the row height by an item row (not by the group header), and the scrolling and the spacing match the rows.
- Review, shortcuts footer: it becomes a named group, announced by screen readers.
- Review, tree: when opening a proposal with the selection beyond the first rows, the list scrolls to the selected one after the measurement; expanding or collapsing a group does not make the list jump back.
- Broken reference in a table cell: the text "(broken reference)" wraps instead of appearing cut off with an ellipsis, at 1280 and 900 px.
- Testing guide (R3.14 to R3.17): the `evolve.py` script generates the `mat-v4` to `mat-v7` copies of the example library again (before it broke with `KeyError 'migrations'` and the steps were swapped), and R3.15 says that Undo takes `specs/` back to version 4.
