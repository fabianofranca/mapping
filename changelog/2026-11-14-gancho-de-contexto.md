# Phase context hook — 2026-11-14 (épico `epic/gancho-de-contexto`, PR #1886, MCP unchanged, schema v19)

## Adicionado

- **A `PostToolUse` hook measures the phase's context after each tool and warns of the handover above 270k (for whoever drives the flow, #1856, GC1):** `scripts/ci/contextGuard.mjs`, wired in `.claude/settings.json` (`hooks.PostToolUse`, `matcher` `*`, `timeout` 10), reads the hook input and measures the main thread's context with the same calculation as `contextUsage.mjs` (`lastContext`, reading only the last 2 MiB of the transcript). It only acts in the cloud (`CLAUDE_CODE_REMOTE=true`), never on a subagent call (`agent_id`) and only in a phase or fix session, which it recognizes by the initial prompt (the "Para a sessão da fase" message of `docs/FLOW.md` or the queue's short prompt, `Fase <código> — … (sub-issue #<n>)`); the coordinator, the tester, the supervision and the owner's chats stay silent. The `GATILHO` constant (270,000) is the single source of the trigger; the 300k ceiling remains.
- **Handover warning with the biggest context jumps (for whoever drives the flow, #1856, GC1):** with the context above the trigger, and at every +10k after the last warning, the hook injects into the session's context (`additionalContext`) the request to hand over (except with the phase PR open or in the `5 de 5` session) and the 3 biggest jumps of the session, each attributed to the tool of the previous call (`Bash: <40 caracteres>`, `Read: <arquivo>`, `Agent: <descrição>` or the tool name). The warning only informs: nothing is blocked. The session state (`fase`, `contexto`, `ferramenta`, `ultimoAviso`, `saltos`, `erro`) lives in `<tmp>/context-guard/<session_id>.json`, and any failure of the hook comes out silently, without delaying the call.

## Alterado

- **The phase context rule in `docs/FLOW.md` now cites the hook and the 270k trigger (for whoever drives the flow, #1856, GC2):** in the "Teto de contexto da fase" sub-item of "Para a sessão da fase", the phase hands over **above the 270k trigger**, in place of "with more than 300k"; the hook's warning (`scripts/ci/contextGuard.mjs`, `PostToolUse`) counts as `acima=true` (except with the PR open or in the `5 de 5` session), and checks (a) and (b) run `node scripts/ci/contextUsage.mjs --teto 270000`, for the epic created before the stage and for the hook that fails silently. The 300k ceiling, the 4 handovers (5 sessions) and the resume line remain. The handover comment (step 3) carries the biggest jumps of the hook's last warning (or "sem aviso do gancho"), to answer with data why a phase grows so fast.
