# Fix in the same proposal — 2026-11-06 (epic `epic/corrigir-proposta`, PR #669, MCP 0.23.0, schema v14)

## Adicionado

- The agent fixes the open proposal in the proposal itself, without creating another, and the review marks what it replaced. The proposal now has `formatVersion` 5, written only by this fix (creation stays at 4).
- **MCP:** the `revise_proposal(ref, { operations?, drop?, dryRun? })` tool replaces, withdraws and adds changes in the open proposal (nothing applied), with the same vocabulary as `propose_changes`; a change the user already accepted is frozen (`change-frozen`). The replaced one goes back to undecided and gets the "Revised" mark; `dryRun` computes without saving. `get_proposal` shows `revised` on each marked change and `revisions` at the root; `get_proposal_review` carries `revisable`, `awaitingUser` (replaced and new ones without a decision, which do not count as rejected) and the notes of the withdrawn changes (`fromDroppedChange`); `list_proposals` carries `lastRevisedAt`. New errors: `change-frozen`, `change-not-found`, `proposal-applied`, `proposal-not-applicable`, `revise-unsupported`.
- **App:** the review shows what the agent fixed in the same proposal. The replaced or added change gets the **Revised** (or **New in the revision**) badge, on its row and on the item that contains it, until you decide. The **Filters** menu gets **Revised only (N)**, the header says "Revised by the agent on <date>: N replaced, N new, N withdrawn", and the Details of the replaced change show **Before the revision**: what the agent had proposed and whether you had rejected it. The Proposals window says "Revised · N to check" on the proposal's row, and the changed-proposal notice now says "The agent revised <title>", with the **Review** button. The note of a withdrawn change goes to the proposal's notes, with "From the withdrawn change: …".

## Alterado

- A decision made at the instant the agent revises the proposal does not apply to the new content: accepting or rejecting a change it just replaced or added is refused ("The agent revised this proposal while you were looking. Check it before deciding."), nothing is saved and the review now shows the new version.
