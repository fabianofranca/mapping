# Block

A 200 × 48 bar as wide as its box, filled with the color its `color` field names. Mark it inside a Scroll: a Block that covers the Scroll's right edge shows the scrollbar on top of it, because the scrollbar has `overlay: true`.

Annotation type: `block` (Block).

| Field   | Type | Description                          |
| ------- | ---- | ------------------------------------ |
| `color` | enum | `blue`, `green` or `amber`: the fill |
