# projetos/

Um projeto Mapping por pasta (`<nome>/mapping.json`, `images/`, `specs/`, `proposals/`). Crie o projeto na app como **pasta**, escolhendo uma subpasta daqui, ou peça ao agente `create_project` com `root: "workspace/projetos"`. Esta pasta é uma raiz do servidor MCP, que procura `mapping.json` em qualquer profundidade.
