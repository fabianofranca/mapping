Esta pasta guarda o histórico do projeto: o plano de cada etapa concluída (objetivo, decisões, fases e decisões consolidadas dos PRs), os relatos de teste e os prompts de coordenação. Até a etapa Sincronia do design system o plano de cada etapa foi arquivado aqui; dali em diante o plano e as decisões ficam na issue da etapa (rótulo `etapa`, com uma sub-issue de rótulo `fase` por fase), e a issue fechada é o histórico. Os relatos de teste continuam sendo gravados aqui.
