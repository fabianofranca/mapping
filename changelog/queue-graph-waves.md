# Queue graph waves — [Não lançado] (épico `epic/queue-graph-waves`, PR #0, MCP unchanged, schema v23)

## Corrigido

- The waves of the queue graph now apply the file and schema conflicts: two waiting stages with a file in common (same rule as the slots, with the ignored and append-only citations) or that both change the schema no longer share a wave; rows with `hold` or an incomplete ficha neither block nor are blocked, and the slots do not cut a wave.
- The reason of a waiting stage in the queue graph, and its arrows, now list every blocker: all its open dependencies and every earlier stage that shares a file or the schema with it, in the reason (joined by `; `) and in "waits for" on the page, instead of only the first one against the running stage.
- A parenthesized note in a stage's `toca=` is now recognized whatever the nesting (`(novo (ver #12))`, `(n)(m)`, or after a path), so it is never a citation and no stray `)` is left behind; the ficha is listed in `fichas a refazer:` and holds no slot.
- A `toca=` with only ignored citations (`changelog/`, `docs/design-system/`, `mcp/version.ts`, the block table) is now `ficha incompleta (toca)` in the queue, conflicts like a `?` once started, and `painel.py toca` and `conflito` refuse it with `only ignored citations`; append-only citations still count.
- A refused fast track now re-enters by comparing two GitHub times: the latest `labeled` event against the `created_at` of the latest `Via rápida recusada:` comment (the row's `ended` only when there is no such comment), so a label put back before the coordinator wrote `ended` is no longer missed.
- The answers that arrive after the End now have a path: the registered coordinator serves a late `soltar #<n>` (it resumes the run when a stage can start, or ends it again) and the owner's `retomar fila`, which re-reads the `ready` issues, the fast tracks and the `recusada` rows; the End table lists each `recusada` row with that hint.
- The cost of a stage brought by `painel.py import` is now marked partial (`meta.partialCost`: the rows with `started`, the stages of the carried canary sessions and the old panel's own list): `costs` ends its line in ` (partial: imported)`, the page shows `(partial)` after its US$ (graph card, "Completed" and the most expensive stages bar), and the per-stage medians (`uso`, the canary sides) and `outliers` leave it out, so it no longer pulls them down; `outliers` prints `, partial: <k>` in its header. The totals do not change.
- `painel.py cost` now refuses a `ctx` in thousands: `ctx=` is the token count (`context_usage.used_tokens`), so 1 to 1000 exits with code 2 and writes nothing (an `Erro` with the line number inside `apply`); `ctx=0` (no measure) still works.
