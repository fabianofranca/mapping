# especializacoes/

Fontes das especializações (`<id>.json`, formato em `docs/SPEC-FORMAT.md` do Mapping). Esta pasta é uma raiz do servidor MCP: `validate_specialization({ path })` e `apply_specialization` leem daqui. A cópia que a app guarda em `projetos/<projeto>/specs/` é derivada; edite sempre a fonte, suba a `version` e aplique de novo por proposta.
