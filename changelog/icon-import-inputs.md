# `import_icons` inputs: SVG from the scratch folder and `ignoreFilters` — [Não lançado] (épico `epic/icon-import-inputs`, PR #0, MCP 0.67.0, schema v25, unchanged)

## Adicionado

- `import_icons` reads its `svg` (a file or a folder) from the scratch folder too (#2931). The path resolves like the `operationsFile` of a batch: a relative path in the roots first and then in the scratch folders, an absolute path inside a root or a scratch folder. The server only reads there and never writes in the scratch folder; the package (`path`) and its icons file stay inside the roots. A path outside both is `outside-roots`, a missing one is `path-not-found`, and a link in a folder that leaves the roots and the scratch folders is an `errors` item of that file only. Without `--scratch` nothing changes.
- `import_icons` takes `ignoreFilters: true` (#2931). Every `filter` of the SVG (the attribute on `svg`, `g` and the shapes, the `filter` property inside `style`, and every `<filter>` element with its content) is dropped and the drawing imports, so a Figma inner-shadow icon no longer needs its `filter` stripped by hand. The shadow itself is not converted. Without the option a `filter` is still an error of that file (`unsupported in SVG: g filter`), and a `mask`, `transform` and the rest stay errors with or without it.
- `import_icons` returns `warnings` (`[{ file, message }]`, `[]` when there is none, in `dryRun` too): one entry per `filter` that `ignoreFilters` dropped, such as `dropped in SVG: g filter="url(#filter0_i_1_2)" (ignoreFilters)`. A file with a warning and no error is imported, or skipped with `icon-exists` with its warning kept.
- The guide (`docs/AGENT-GUIDE.md`) and the `spec-author` skill tell the agent that the `svg` may be in the scratch folder and when to use `ignoreFilters`.
- `tests/model/components/svgIconFilters.test.ts` and `tests/mcp/iconImportInputs.test.ts` cover both, with the Figma-form fixture `tests/fixtures/svg-icons/filter/inner-shadow.svg`. The script `docs/TESTING.md#R39` gains R39.20 and R39.21 (block 6 of the full round, 2 more steps).
