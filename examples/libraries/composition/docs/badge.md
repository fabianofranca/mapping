# Badge

A count pill: at least 16 wide, it grows with the text (`3`, `12`, `99+`). Its root `anchor` is `{ "side": "top", "align": "corner-end" }`, so a badge that is anchored to a marking has its center on that marking's top-end corner.

Annotation type: `badge` (Badge).

| Field   | Type   | Description       |
| ------- | ------ | ----------------- |
| `count` | string | The text it shows |
