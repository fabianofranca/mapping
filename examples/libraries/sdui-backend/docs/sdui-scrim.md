# Scrim

Film that darkens the screen behind a modal: black at 32%. It covers the whole screen, below the sheet.

Annotation type: `sdui-scrim` (Scrim).

## Size

- Initial: 412 × 917 px
- Minimum: 16 × 16 px
- Sizing: width fill, height fill
