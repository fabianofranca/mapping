# Leaner CI — 2026-11-03 (epic `epic/ci-enxuta`, PR #392, MCP 0.13.0, schema v13)

## Alterado

- Each PR commit goes through CI only once: CI no longer runs on branch push, only on the PR.
- The preview (`/preview/`) goes out after the PR's CI is green and publishes exactly the validated commit, without running validation again.
- The manual Deploy trigger stays the same: it runs CI on the branch before publishing.
- The CI `check` job becomes an aggregator of four parallel jobs (`static`, `test` in 2 shards + `coverage`, `build`), with a cache for `node_modules`, ESLint/Prettier and the Playwright browser; the required checks remain `check`, `e2e` and `epic`.
- The component tests (the `app` Vitest project) run in `vmThreads`, without recreating jsdom for each file: the full suite drops from ~175 s to ~97 s locally.
- `npm run build` and `npm run build:mcp` stop repeating `tsc --noEmit`: types are checked only by `npm run typecheck`.
